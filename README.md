Por ser meu primeiro programa de automação, decidi fazer por partes.
A primeira parte vai ser responsável por acessar o SAP, sistema que utilizo no meu trabalho, acesse e exporte 2 das transações necessárias e aplique em cada uma
operações na planilha de excel que vão preparar meus dados para a segunda parte do programa.

1- Abrir SAP
2- Entrar na primeira conexão
3- Rodar KSB1
4- Preencher variante
5- Executar
6- Exportar Excel
7- Tratar Excel
8- Voltar SAP
9- Rodar KOB1
10- Colar ordens
11- Exportar
12- Tratar Excel
